# 2026-016-AD学习

本仓库是一个 Altium Designer 学习与实验资料归档集合，主要包含实验工程、参考资料、器件库文件，以及一些保留但未继续使用的历史内容。

## 项目说明

- 项目类型：EDA / PCB / 原理图学习资料
- 主要工具：Altium Designer
- 归档状态：项目已结束，当前内容以保留和整理为主
- 目录用途：便于后续查看实验工程、复用库文件，以及完成交接归档

## 目录结构

```text
2026-016-AD学习/
├─ a2-实验1/                          # 实验1工程，包含原理图、PCB、库文件和历史记录
├─ a3-基于STM32的DDS信号源的设计实例/   # 基于 STM32 的 DDS 信号源设计示例工程
├─ b-References/                      # 参考资料
├─ Unused/                            # 已保留但未继续使用的相关资源
├─ z-AD库文件汇总/                    # Altium Designer 库文件汇总
├─ Logo.png                           # 项目标识图片
├─ Note.txt                           # 备注文件
└─ README.md                          # 当前归档说明
```

## 主要内容

### `a2-实验1`

包含实验1的完整 Altium 工程资料，例如：

- `PCB.PcbDoc`
- `SCH.SchDoc`
- `PCBL.PcbLib`
- `SCHL.SchLib`
- `Project.PrjPcb`
- 历史版本与项目日志

### `a3-基于STM32的DDS信号源的设计实例`

包含一个基于 STM32 的 DDS 信号源设计实例工程，工程中可见：

- 原理图与 PCB 文件
- 原理图库与封装库
- 工程文件与 BOM 文件
- 自建元件库与自建封装库

### `z-AD库文件汇总`

这里汇总了常用的 Altium Designer 库资源，包括：

- 元件库
- 封装库
- 集成库
- 规则文件
- 其他常用器件模型

### `Unused`

该目录保留了若干未继续使用的资料，包含不同软件/模块导出的工程文件、Office 文档、图片、视频和其他辅助资源。

## 归档建议

- 如果需要长期保存，建议优先保留：
  - 最终版工程文件
  - 关键库文件
  - 项目总结或报告
  - BOM 和输出文档
- 如果需要压缩存档，建议将 `Unused/` 中不再使用的内容单独打包，减少主归档体积。
